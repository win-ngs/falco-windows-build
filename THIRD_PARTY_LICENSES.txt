Third-party notices for Falco 1.3.0 Windows binary releases
===========================================================

This repository distributes Windows binary builds of Falco 1.3.0 from:

https://github.com/smithlabcode/falco

The release archives bundle MSYS2 runtime DLLs so the binaries can run from a
normal Windows shell without requiring MSYS2 on PATH.

Windows system DLLs reported by ldd, such as ntdll.dll, KERNEL32.DLL,
KERNELBASE.dll, ucrtbase.dll, WS2_32.dll and related Windows DLLs, are provided
by Windows and are not bundled in the release archives.
